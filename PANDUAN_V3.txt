INSTALASI:

- Buat database dinas_smp.
- Import database/dinas_smp_v3.sql setelah database/dinas_smp_v2.sql (atau gunakan SQL V2 lalu SQL V3).
- Edit config/database.php.
- Pastikan uploads dapat ditulis.
- Login admin: admin / admin123, lalu ubah password.
